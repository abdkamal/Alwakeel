unicode-bidi: plaintext — الفقرة تأخذ اتجاه أول حرف قوي فيها، وهو المطلوب للملاحظات والنص المستخرج بـ OCR

قواعد البناء (البند 55)

  1. الجذر <html dir="rtl" lang="ar"> والاتجاه الأساسي RTL لكل الشاشات مهما كان أول حرف.
  2. كل رمز لاتيني أو رقمي (رقم رسمي، معرّف جهاز، اسم ملف، إصدار، مصطلح تقني، مبلغ، تاريخ) داخل <bdi> أو unicode-bidi: isolate.
  3. النص الحر (الملاحظات، النص المستخرج، الرسائل) بـ unicode-bidi: plaintext.
  4. خصائص CSS منطقية فقط: margin-inline-start وpadding-inline وinset-inline؛ لا left ولا right.
  5. الأيقونات ذات الاتجاه (أسهم، رجوع، شيفرون) تُعكس في RTL؛ الأيقونات الرمزية لا تُعكس.
  6. أندرويد: LocalLayoutDirection وBidiFormatter.unicodeWrap للسلاسل المختلطة، وTextDirection.ContentOrRtl للنص الحر.
  7. Word وPDF: فقرات RTL مع تشغيلات bidi للرموز اللاتينية داخل القالب الرسمي.
  8. هذه الحالات تُضاف إلى اختبارات الواجهة الآلية وتُقارن لقطاتها في كل إصدار.
